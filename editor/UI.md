# UI Design Tokens

## Colors

| Token | Value | Usage |
|-------|-------|-------|
| `COLOR_ACCENT` | `#ffbf4d` | Highlights requiring attention (e.g., recommended differs from actual) |
| `COLOR_MUTED` | `#808080` | De-emphasized labels |
| `COLOR_WARNING` | `#ff4500` | Problems the user must act on (e.g., a placement that breaks a balance rule) |
